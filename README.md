# Travel Journal 🌍

A modern React Native travel journal app built with Expo and NativeWind.

Users can:
- Add new cities
- Mark cities as visited
- Delete cities
- Search cities
- Use dark mode
- Track visited city count

## Features

- React Native + Expo
- TypeScript
- NativeWind (Tailwind CSS)
- FlatList rendering
- Search & filter
- Dark mode support
- KeyboardAvoidingView
- Component-based architecture
